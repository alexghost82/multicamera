# ACTA: применение предоставленного SwiftUI-кода — 16 ноября 2026

После замечания пользователя прежняя стилизация заменена прямым использованием компонентов из приложенного файла. `ACTAReferenceDashboard.swift` содержит исходные `NeonGlow`, `ActiveMenuButton`, `InactiveMenuButton`, `HeaderIconButton`, `AIModuleCell`, `CircularProgressView`, `FilterTag`, `EventCategoryCard`. В `DashboardView` сохранены HStack с sidebar 260 pt, VStack spacing 16 и padding 16, порядок header → metrics → filters → cameras → analytics. Вместо статических демонстрационных блоков его слоты принимают работающие экраны ACTA.

Используются исходные цвета и трёхслойное свечение. Верхняя панель повторяет структуру исходного кода: заголовок, поиск, компактные кнопки и язык. Основное меню повторяет порядок макета; дополнительные рабочие разделы доступны через «Системы». Видеосетка открывается в четыре колонки, как в макете, даже при одной камере; выбор другой сетки остаётся рабочим; расширение камеры по-прежнему занимает одну колонку. Временная шкала вдоль видеостены удалена из этого экрана, поскольку её нет в предоставленном макете.

Карточки модулей используют исходный AIModuleCell с настоящими названиями и состояниями моделей. Круговая RAM показывает измеренное значение; GPU без доступной телеметрии отображает «—». Нижняя панель использует исходный EventCategoryCard и диаграмму по фактически сохранённым событиям. Демонстрационные камеры, проценты и счётчики не выданы за реальные данные.
