## Стоп-условия

- Gate A approval получен.
- Phase 1 Gate B acceptance set passed; расширенное safety-quality qualification остаётся отдельным gate.
- Core ML export/task/keypoint contract не совпадает с проверенным PyTorch baseline.
- Появляется необходимость менять текущий RTSP connection, камеру, сеть, service/autostart, UI flow или внешнюю интеграцию без отдельного разрешения.
- Предлагается объявить fight/fall/incapacitation production-ready без независимой валидации, human verification и false-alarm измерения.
